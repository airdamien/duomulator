# Duomulator Privacy Policy

_Effective October 22, 2026_

Duomulator is a game emulator for iPhone. It doesn't collect, store, or share any personal
information, and it has no accounts, analytics, advertising, or tracking.

## What stays on your iPhone

Your games, BIOS files, save files, save states, captured title screens and settings are
stored only in Duomulator's folder on your iPhone. They're never sent to us; we don't run
any servers. iOS may include this folder in your iCloud or computer backups, under your
backup settings and Apple's privacy policy.

## Network use

The App Store version of Duomulator makes no network requests at all.

Builds you compile yourself from the source code add an optional **Download Box Art**
setting (off by default). If you turn it on, Duomulator requests
cover images for the games in your library from a community image server (by default
`thumbnails.libretro.com`, run by the libretro project). Each request contains the
console and game name in the address. Like any web server, that server can see your
device's IP address. The libretro project's policies govern those requests. Duomulator
sends nothing else, and you can turn the setting off and delete downloaded art at any time.

## What we don't do

- No personal data is collected, including names, email addresses, contacts, location or
  identifiers.
- No analytics, crash-reporting or advertising SDKs are included.
- No data is sold or shared with anyone.
- Nothing is tracked across apps or websites.

## Children

Duomulator doesn't knowingly collect information from anyone, including children under 13.

## Changes

If this policy changes, the new version will be posted on this page with a new effective date.
